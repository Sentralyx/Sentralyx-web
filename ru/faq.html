Безопасность и конфиденциальность

При отключении интернет-соединения ваши позиции остаются полностью в безопасности. Sentralyx работает с принципами GTC ордеров (Good Till Canceled) и Server-Side Protection:

✅ SL/TP защита: Ордера Stop Loss и Take Profit хранятся непосредственно на сервере биржи и остаются активными независимо от наличия интернет-соединения.
  • SL (Stop Loss): Когда цена достигает вашего стоп-уровня, позиция автоматически закрывается.
  • TP (Take Profit): При достижении целевой цены ваша прибыль реализуется.
  • Global Stop: В экстренных ситуациях вы можете безопасно закрыть все позиции.

Важно: Во время перебоев с интернетом новые ордера отправлять нельзя (мера безопасности), но существующие позиции защищены на стороне сервера.

Ваши API ключи защищены с максимальной безопасностью с помощью HWID шифрования:

🔐 Двойное шифрование: Комбинация идентификатора оборудования (HWID) и симметричного шифрования Fernet.
  • Привязка к HWID: Каждая лицензия предназначена для конкретного оборудования. Не будет работать на разных машинах.
  • Локальное хранение: API ключи никогда не отправляются в облако или на сторонние серверы.
  • Fernet шифрование: Используется стандарт шифрования на основе AES-128, безопасенный для URL.
  • Соответствие регуляторам: Полностью соответствует законам о защите данных GDPR и KVKK.

Дополнительная безопасность: Ваши API ключи могут быть расшифрованы только с помощью HWID вашей машины, что делает несанкционированный доступ невозможным.

  • Передача данных: Критические данные никогда не передаются через интернет.
🛡️ Нулевой риск посредника: Все критические операции и данные хранятся локально для максимальной безопасности.

Техническая стабильность (Self-Healing)

Sentralyx имеет возможности самовосстановления с системой ThreadWatchdog:

🔄 24/7 Автоматический мониторинг: Все критические потоки проверяются каждые 30 секунд.
  • Контроль сердцебиения: Специальная система сердцебиения для потока сканера, сигнал "frozen" если нет данных 60 секунд.
  • Автоматический перезапуск: Если обнаружен сбой потока, он автоматически перезапускается.
  • Максимум попыток: Каждый поток имеет максимум 3 попыток перезапуска.
  • State-Safe: Данные позиций и состояние стратегий сохраняются во время перезапусков.

Слои самовосстановления:

  1. Pre-Trade Validation: Проверка баланса, анализ риска, лимит максимальной позиции.
  2. Real-Time Monitoring: Обнаружение скачков цен, обнаружение аномалий, отслеживание P&L.
  3. Emergency Protocols: Механизм глобальной остановки, возможность принудительного закрытия.

Да, целостность файлов обеспечивается с гарантией Atomic Write I/O:

⚛️ Атомарные операции: Критические операции либо полностью успешны, либо считаются несостоявшимися.
  • Транзакционные файловые операции: Запись во временный файл, проверка, затем атомарная замена.
  • Crash Recovery: Целостность данных поддерживается даже во время отключений электроэнергии или сбоев системы.
  • Свойства ACID: Гарантия Atomicity, Consistency, Isolation, Durability.
  • Sync Guarantee: Используется fsync для обеспечения записи данных на диск.

Пример потока:

  1. Данные записываются во временный файл (.tmp)
  2. Выполняется синхронизация с диском (fsync)
  3. Атомарная замена с оригинальным файлом (rename)
  4. Временный файл удаляется при ошибке

Система Orphan Recovery автоматически управляет осиротевшими позициями при прерываниях соединения:

  • Быстрое обнаружение: Прерывание соединения обнаруживается в течение 5 секунд.
  • Автоматическая синхронизация: При восстановлении соединения состояние позиций автоматически синхронизируется.
  • State Recovery: Состояние системы в момент сбоя сохраняется и может быть восстановлено.
  • Manual Override: При необходимости предоставляется возможность ручного вмешательства.
🛡️ 100% успешность восстановления: Потеря позиций при прерываниях соединения отсутствует.

Конфигурация системы и технические параметры

Движок анализа Multi-Timeframe (MTF) Sentralyx поддерживает следующие технические конфигурации:

  • Модули скальпинга (1m, 5m): Оптимизированы для высокочастотной обработки данных с анализом низкой задержки.
  • Внутридневные модули (15m, 1h): Стандартная конфигурация для сбалансированной плотности сигналов и частоты торговли.
  • Свинг-модули (4h, 1d): Высокоточные вычисления для долгосрочного трендового анализа.

Алгоритм подтверждения MTF: Математическая корреляция сигналов из нескольких таймфреймов рассчитывает показатель уверенности торговых решений.

📊 Техническое примечание: Система по умолчанию синхронно запускает модули 15m и 1h.

  • Максимальная продолжительность: 240 минут (4 часа) таймер автоматического закрытия

Валидация системы: Параметры риска проверяются слоем Pre-Trade Validation перед каждой сделкой.

Математические эквиваленты модулей технического анализа, интегрированных в движок Sentralyx:

Модули трендового анализа:

  • MACD (12, 26, 9) - Алгоритм схождения/расхождения скользящих средних
  • Moving Averages (20, 50) - Движок расчета экспоненциальных и простых скользящих средних
  • ADX - Алгоритм измерения силы тренда Average Directional Index

Модули возврата к среднему:

  • RSI (14) - Осциллятор Relative Strength Index (порог 30/70)
  • Bollinger Bands - Расчет ценового канала на основе стандартного отклонения
  • Stochastic Oscillator - Анализ импульса линий %K и %D

Модули анализа объема:

  • Volume Profile - Алгоритм гистограммы распределения цены/объема
  • On-Balance Volume - Движок расчета направления потока
💡 Техническое примечание: Модули работают не индивидуально, а через матрицу корреляции сигналов.

Процедура технической валидации для движка бэктестинга Sentralyx:

  1. Подготовка набора данных: Минимум 6-месячные данные OHLCV (поддерживается tick-by-tick)
  2. Определение стратегии: Алгоритмическое определение правил входа/выхода
  3. Оптимизация параметров: Алгоритм поиска по сетке для сканирования пространства параметров
  4. Walk-Forward валидация: Тест out-of-sample для контроля переобучения
  5. Метрики риска: Расчет максимальной просадки, коэффициента Шарпа, коэффициента Сортино

Метрики производительности (Техническая справка):

  • Max Drawdown: Ниже 20% (толерантность к риску)
  • Sharpe Ratio: 1.0+ (доходность с поправкой на риск)
