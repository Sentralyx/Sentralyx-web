Разрешения следует ограничивать, проверять и отзывать при подозрительной активности.

Включать нужно только те разрешения API, которые требуются для выбранного сценария. Для наблюдения за рынком может быть достаточно чтения; для отправки ордеров может понадобиться торговое разрешение. Backtest — это проверка стратегии на исторических рыночных данных. Цель состоит в том, чтобы увидеть, как набор правил работал раньше, и найти слабые места до реальной торговли.
