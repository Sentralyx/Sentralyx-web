Как создать безопасный API-ключ Binance

21 ноября 2026 · 3 мин чтения

Чтобы приложение вроде Sentralyx могло торговать на вашем биржевом счёте, ему нужен API-ключ. API-ключ даёт доступ к счёту с определёнными разрешениями, поэтому создавать и хранить его нужно так же внимательно, как пароль.

Что такое API-ключ?

API-ключ состоит из двух частей: API Key и Secret Key. С их помощью приложение представляется бирже и может делать только то, что разрешено. Иными словами, возможности ключа определяются разрешениями, которые вы выбираете при его создании.

Пошагово

Интерфейс Binance время от времени меняется; шаги ниже описывают общий порядок действий.

  1. Войдите в Binance и откройте раздел «Управление API» в меню профиля.
  2. Создайте новый API и выберите тип ключа, сгенерированного системой.
  3. Дайте ключу название, которое напомнит, для чего он (например, «Sentralyx»).
  4. Пройдите необходимые проверки безопасности.
  5. Сохраните API Key и Secret Key в надёжном месте. Secret Key обычно показывается только один раз.
  6. Настройте разрешения ключа (см. ниже) и сохраните.

Какие разрешения включать?

  • Чтение: нужно для информации о балансе и позициях; обычно включено по умолчанию.
  • Спотовая торговля: нужна для отправки ордеров на спотовом рынке.
  • Фьючерсы: включайте, только если будете торговать фьючерсами (например, в гибридном или полностью фьючерсном режиме).
  • Вывод средств: должен оставаться выключенным. Торговому приложению не нужно выводить средства.

Правило простое: включайте только те разрешения, которыми действительно будете пользоваться. Каждое лишнее разрешение — это ненужный риск, если ключ будет скомпрометирован.

Ограничение по IP

Binance позволяет ограничить API-ключ так, чтобы им можно было пользоваться только с определённых IP-адресов. Если у вас статический IP-адрес, такое ограничение даёт дополнительный уровень защиты. Если нет, уточните в документации Binance, как эта настройка влияет на разрешения ключа.

Как защитить ключ

  • Никому не передавайте ключ и не отправляйте его скриншоты в сообщениях.
  • Держите на биржевом счёте включённой двухфакторную аутентификацию (2FA).
  • Удаляйте ключи, которыми больше не пользуетесь.
  • Если подозреваете, что ключ скомпрометирован, сразу удалите его и создайте новый.
  • Следите и за безопасностью компьютера, на котором используется ключ.

Что приложение делает с ключом?

Торговое приложение использует API-ключ для запросов к бирже: чтения баланса и позиций, отправки ордеров, выставления и отмены стоп-ордеров и тейк-профитов. Пока разрешение на вывод выключено, ключом нельзя воспользоваться, чтобы отправить деньги со счёта. Поэтому отключённый вывод средств — самый важный шаг безопасности.

Короткое замечание для OKX

На OKX API-ключ создаётся похожим образом; отличие в том, что при создании ключа задаётся passphrase (кодовая фраза). Она так же важна, как API Key и Secret Key, и её нужно ввести в приложении. Правило для разрешений то же: только чтение и торговля, вывод выключен.

Когда обновлять ключ?

  • Если подозреваете, что передали ключ другому человеку или сервису.
  • Если сменили или переустановили компьютер.
  • Если видите на счёте незнакомую сделку или вход.
  • Регулярно, как привычку безопасности.

Частые ошибки

  • Включать вывод средств «на всякий случай».
  • Хранить Secret Key открытым текстом в блокноте, письме или облачной заметке.
  • Использовать один ключ в нескольких приложениях: при проблеме не понять, какое приложение её вызвало.
  • Забывать удалять старые неиспользуемые ключи.

Как ввести ключ в Sentralyx

API Key и Secret Key вводятся в разделе API настроек Sentralyx. Для OKX дополнительно нужна passphrase. Sentralyx шифрует ключи ключом, полученным из аппаратного идентификатора устройства, и хранит их на вашем компьютере; файл настроек, скопированный на другое устройство, расшифровать нельзя.

Без API-ключа реальный режим выбрать нельзя, а при переходе в него появляется окно подтверждения. Начиная работу с новым ключом, безопаснее всего сначала проверить настройки в виртуальном режиме.

Ключи остаются зашифрованными на вашем устройстве

Sentralyx шифрует API-ключи ключом, полученным из аппаратного идентификатора устройства, хранит их локально и рекомендует отключить разрешение на вывод средств.
