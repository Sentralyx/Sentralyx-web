How to Create a Secure Binance API Key

November 21, 2026 · 3 min read

An app like Sentralyx needs an API key to trade on your exchange account. An API key gives access to your account with specific permissions, so you need to create and store it as carefully as a password.

What is an API key?

An API key has two parts: the API Key and the Secret Key. The app uses them to identify itself to the exchange and can only do what your permissions allow. In other words, the permissions you choose when creating a key decide what it can do.

Step by step

Binance's interface changes from time to time; the steps below describe the general flow.

  1. Log in to Binance and open API Management from the profile menu.
  2. Create a new API and choose the system-generated key type.
  3. Give the key a name that reminds you what it is for (e.g. "Sentralyx").
  4. Complete the required security verifications.
  5. Save the API Key and Secret Key somewhere safe. The Secret Key is usually shown only once.
  6. Edit the key's permissions (see below) and save.

Which permissions should be enabled?

  • Read permission: needed for balance and position information; usually enabled by default.
  • Spot trading permission: needed to send orders on the spot market.
  • Futures permission: enable it only if you will trade futures (e.g. hybrid or full futures mode).
  • Withdrawal permission: should stay disabled. A trading app does not need to withdraw funds.

The rule is simple: enable only the permissions you will actually use. Every unused permission is unnecessary risk if the key is ever compromised.

IP restriction

Binance lets you restrict an API key so it can only be used from specific IP addresses. If you have a static IP address, this restriction adds an extra layer of security. If you do not, check Binance's own documentation for how this option affects the key's permissions.

How to protect your key

  • Do not share the key with anyone, and do not send screenshots of it in messages.
  • Keep two-factor authentication (2FA) enabled on your exchange account.
  • Delete keys you no longer use.
  • If you suspect a key has been compromised, delete it immediately and create a new one.
  • Also take care of the security of the computer where you use the key.

What does the app do with the key?

A trading app uses the API key to send requests to the exchange: reading balance and position information, sending orders, and placing or cancelling stop and take-profit orders. As long as the withdrawal permission is disabled, the key cannot be used to send money out of your account. That is why keeping withdrawals disabled is the most important security step.

A short note for OKX

Creating an API key on OKX works in a similar way; the difference is that you set a passphrase when creating the key. This passphrase is as important as the API Key and Secret Key and must be entered in the app. The same rule applies to permissions: read and trade only, withdrawals disabled.

When should you renew your key?

  • If you suspect you shared the key with another person or place.
  • If you changed or reset your computer.
  • If you see a trade or login on your account that you do not recognize.
  • At regular intervals, as a security habit.

Common mistakes

  • Enabling the withdrawal permission "just in case".
  • Saving the Secret Key as plain text in a notepad, email or cloud note.
  • Using the same key in several apps; when something goes wrong you cannot tell which app caused it.
  • Forgetting to delete old keys that are no longer used.

How to enter it in Sentralyx

The API Key and Secret Key are entered in the API section of the Sentralyx settings. If you use OKX, a passphrase is also required. Sentralyx encrypts the keys with a key derived from your device's hardware ID and stores them on your computer; a settings file copied to another device cannot be decrypted.

Real mode cannot be selected without an API key, and a confirmation window appears when switching to real mode. When starting with a new key, trying it in virtual mode first is the safest way to make sure your settings work correctly.

Keep your keys encrypted on your device

Sentralyx encrypts API keys with a key derived from your device's hardware ID, stores them locally and recommends keeping the withdrawal permission disabled.
