Binance API Anahtarı Güvenli Nasıl Oluşturulur?

21 Kasım 2026 · 3 dk okuma

Sentralyx gibi bir uygulamanın borsa hesabında işlem yapabilmesi için bir API anahtarına ihtiyacı vardır. API anahtarı, hesabına belirli izinlerle erişim sağlayan bir anahtardır; bu yüzden onu bir şifre kadar dikkatli oluşturman ve saklaman gerekir.

API anahtarı nedir?

Bir API anahtarı iki parçadan oluşur: API Key ve Secret Key. Uygulama bu ikisiyle borsaya kendini tanıtır ve yalnızca senin verdiğin izinler kadar işlem yapabilir. Yani bir anahtarın neler yapabileceğini, oluştururken seçtiğin izinler belirler.

Adım adım oluşturma

Binance'in arayüzü zaman zaman değişebilir; aşağıdaki adımlar genel akışı anlatır.

  1. Binance hesabına giriş yap ve profil menüsünden API Yönetimi bölümünü aç.
  2. Yeni bir API oluştur ve sistem tarafından oluşturulan anahtar türünü seç.
  3. Anahtara ne için kullandığını hatırlatacak bir ad ver (ör. "Sentralyx").
  4. İstenen güvenlik doğrulamalarını tamamla.
  5. Oluşan API Key ve Secret Key'i güvenli bir yere kaydet. Secret Key genellikle yalnızca bir kez gösterilir.
  6. Anahtarın izinlerini düzenle (aşağıya bak) ve kaydet.

Hangi izinler açılmalı?

  • Okuma izni: Bakiye ve pozisyon bilgisi için gereklidir; genellikle varsayılan olarak açıktır.
  • Spot işlem izni: Spot piyasada emir göndermek için gerekir.
  • Vadeli işlem izni: Yalnızca vadeli işlem kullanacaksan (ör. hibrit ya da tam vadeli mod) aç.
  • Para çekme izni: Kapalı kalmalı. Bir trading uygulamasının para çekmeye ihtiyacı yoktur.

Kural basit: Yalnızca gerçekten kullanacağın izinleri aç. Kullanmadığın her izin, anahtar ele geçirildiğinde gereksiz bir risk demektir.

IP kısıtlaması

Binance, bir API anahtarını yalnızca belirli IP adreslerinden kullanılacak şekilde sınırlamana izin verir. Sabit bir IP adresin varsa bu kısıtlama ek bir güvenlik katmanı sağlar. Sabit IP'n yoksa bu seçeneğin anahtarın izinlerine etkisini Binance'in kendi açıklamalarından kontrol et.

Anahtarını nasıl korursun?

  • Anahtarı kimseyle paylaşma; ekran görüntüsünü mesaj olarak gönderme.
  • Borsa hesabında iki aşamalı doğrulamayı (2FA) açık tut.
  • Kullanmadığın anahtarları sil.
  • Bir anahtarın ele geçirildiğinden şüphelenirsen hemen sil ve yenisini oluştur.
  • Anahtarı kullandığın bilgisayarın güvenliğine de dikkat et.

Uygulama anahtarla ne yapar?

Bir trading uygulaması API anahtarını borsaya istek göndermek için kullanır: bakiye ve pozisyon bilgisini okumak, emir göndermek, stop ve kâr al emirlerini yerleştirmek ya da iptal etmek. Para çekme izni kapalı olduğu sürece anahtar, hesabından dışarıya para göndermek için kullanılamaz. Bu yüzden para çekme iznini kapalı tutmak en önemli güvenlik adımıdır.

OKX için kısa not

OKX'te API anahtarı oluşturma mantığı benzerdir; fark, anahtar oluşturulurken bir passphrase (parola) belirlenmesidir. Bu parola da API Key ve Secret Key kadar önemlidir ve uygulamaya girilmesi gerekir. İzin seçiminde de aynı kural geçerlidir: Yalnızca okuma ve işlem izinleri, para çekme kapalı.

Anahtarını ne zaman yenilemelisin?

  • Anahtarı başka bir kişiyle ya da yerle paylaştığından şüpheleniyorsan.
  • Bilgisayarını değiştirdiysen ya da sıfırladıysan.
  • Hesabında tanımadığın bir işlem ya da giriş görürsen.
  • Belirli aralıklarla, düzenli bir güvenlik alışkanlığı olarak.

Sık yapılan hatalar

  • "Lazım olur" diye para çekme iznini açmak.
  • Secret Key'i not defterine, e-postaya ya da bulut notlarına düz metin olarak kaydetmek.
  • Aynı anahtarı birden fazla uygulamada kullanmak; bir sorun olduğunda hangi uygulamadan kaynaklandığını bilemezsin.
  • Artık kullanılmayan eski anahtarları silmeyi unutmak.

Sentralyx'e nasıl girilir?

API Key ve Secret Key, Sentralyx'in ayarlarındaki API bölümüne girilir. OKX kullanıyorsan ayrıca bir passphrase (parola) istenir. Sentralyx anahtarlarını cihazının donanım kimliğinden türetilen bir anahtarla şifreleyip bilgisayarında saklar; ayar dosyası başka bir cihaza kopyalansa bile çözülemez.

API anahtarı girilmeden gerçek mod seçilemez; gerçek moda geçerken de bir onay penceresi çıkar. Yeni bir anahtarla başlarken önce sanal modda denemek, ayarların doğru çalıştığından emin olmanın en güvenli yoludur.

Anahtarların cihazında şifreli kalsın

Sentralyx, API anahtarlarını cihazının donanım kimliğinden türetilen bir anahtarla şifreleyip yerelde saklar ve para çekme izninin kapalı olmasını önerir.
