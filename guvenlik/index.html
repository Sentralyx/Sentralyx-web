Güvenlik ve API Anahtarları

Sentralyx kullanımında API anahtarı izinleri, cihaz güvenliği ve risk yönetimi kullanıcı için kritik konulardır. Bu sayfa genel güvenlik değerlendirmelerini açıklar.

Masaüstü çalışma modeli

Sentralyx, sitede masaüstü trade terminali olarak anlatılır. Kullanıcı uygulamayı kendi cihazında çalıştırır ve borsa bağlantı ayarlarını kendi hesabı üzerinden yapılandırır.

API anahtarı kapsamı

API anahtarları yalnızca gerekli işlem kapsamıyla oluşturulmalıdır. Para çekme izni verilmemelidir. Borsa hesabındaki izinleri kontrol etmek kullanıcının sorumluluğundadır.

Yerel çalışma

Ürün belgelerine göre Sentralyx kullanıcının kendi cihazında yerel olarak çalışır. Kullanıcı cihaz güvenliğini, erişim bilgilerini ve dosyalarını korumalıdır.

Kullanıcı sorumlulukları

  • API anahtarına para çekme izni vermemek
  • Gereksiz yetkileri kapatmak
  • Stop loss ve risk limitlerini kontrol etmek
  • Backtest sonucunu canlı işlem garantisi gibi yorumlamamak
Güvenlik ayarları borsa hesabı, cihaz ve kullanıcı tercihleriyle birlikte değerlendirilmelidir.
